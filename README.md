# Win Tracker

A React app for logging your daily wins. Built by me, to remind yourself that you're making progress, even on slow days.

<img width="1918" height="925" alt="win-tracker-screenshot" src="https://github.com/user-attachments/assets/3ae252a5-5298-4923-ac36-7ce3e0df9bf3" />


## Live Demo

https://win-tracker-react.onrender.com/

## Features

- Add a win and submit with button or Enter key
- Latest win always appears at the top
- Edit or delete any win
- Empty submissions are blocked
- Smooth fade-in animation on new entries

## Tech Stack

- React (Vite)
- Plain CSS
- Deployed on Render

## Getting Started

```bash
git clone https://github.com/Allkindoflower/win-tracker-react
cd win-tracker-react
npm install
npm run dev
```
